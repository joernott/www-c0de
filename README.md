# www-c0de

The website [c0de.at](https://c0de.at) with the documentation and tutorials of the Minecraft mod [c0de](https://github.com/joernott/minecraft-c0de) and its companion mods. The site is built with Vue.js and Tailwind CSS and served by Caddy from a single static Go binary, which also runs in a Docker container.
