# Programmieren lernen

Für alle, die noch nie programmiert haben. Jede Lektion stellt eine Idee des Programmierens vor, gibt ihr einen Namen und zeigt sie in c0de. Lektion für Lektion baust du den Computer deiner Basis: Aus einem Schild, das Besucher begrüßt, werden eine bewachte Tür mit Besucherzähler, ein Schwarzes Brett und ein Spiel.
