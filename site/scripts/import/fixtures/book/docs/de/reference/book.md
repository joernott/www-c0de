# Das Buch-Handbuch

Das Buch fügt die Bibliothek b/c hinzu. Es zeichnet mit [ZAP](#zap).

## Erste Schritte

Binde die Bibliothek ein.

## Typen

Die Typen der Bibliothek.

### THING

Ein Ding zum Zeichnen.

## Zeichnen

Wie man zeichnet.

### ZAP

Zappt ein [THING](#thing).

### ZIP und ZAP_ALL

Zippt und zappt alles.

## Fehler

### OOPS

Etwas ging schief.
