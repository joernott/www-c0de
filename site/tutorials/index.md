# Tutorials

The tutorials teach c0de by building things in the game. Every lesson is a complete program that you build, run and change, with exercises and their solutions. Pick the path that fits you:

| Path                                            | For you if …                                                | You learn                                                                                                        |
| ----------------------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [Learning to program](/tutorials/learning/)     | you have never programmed before                            | the ideas of programming, one at a time, and how c0de expresses them – while you build the computer of your base |
| [c0de for programmers](/tutorials/programmers/) | you already program in Python, JavaScript, Java, C or BASIC | the model and the rules of c0de, compared with the languages you know, and the traps                             |
| [Libraries in practice](/tutorials/libraries/)  | you know the language                                       | the library functions, with recipes that build something useful                                                  |

The first two paths don't depend on each other. After either of them, go on with the libraries.

## The world of the tutorials

The tutorials assume a **single-player world in creative mode with cheats on**. You have every block at hand, and you are an operator of your world.

- Create it in Minecraft with "Create New World": game mode **Creative**, **Allow Cheats: ON**. The mods c0de (and c0de net for its recipes) must be installed.
- Lessons that change the world with functions of c0de/minecraft only work for operators, or on a server that allows them in `config/c0de.properties`. They are marked with **Needs an operator**, and they show the alternative for everyone where there is one.
- In survival mode, you craft the blocks first. The recipes are in the [handbooks](/c0de/).

## How to read the programs

The programs are written in the text notation of the guide ([Reading the examples](/c0de/guide/getting-started#reading-the-examples)): one line of text per line of the sheet, four spaces per block further east, keywords in capitals, names in lower case, literals and operators in between. Every program in the tutorials is tested with the c0de version this site documents.
