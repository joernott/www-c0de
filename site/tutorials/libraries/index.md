# Libraries in practice

Recipes for the library functions: every recipe builds something useful in the game and uses several functions of one library. The recipes are sorted by library; every function of every library appears in at least one of them.

## The libraries

- [c0de/math](/tutorials/libraries/c0de/math/): dice, distances, circles, angles and growth
- [c0de/strings](/tutorials/libraries/c0de/strings/): name boards, commands, secret messages and data as text
- [c0de/time](/tutorials/libraries/c0de/time/): clocks, calendars, stopwatches and game time
- [c0de/minecraft](/tutorials/libraries/c0de/minecraft/): music, locks, doors, storage, building and mining
- [c0de_net/http](/tutorials/libraries/c0de_net/http/): the weather, REST services, status checks and home automation
